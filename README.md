# Desafío 1 - Lista de Contactos 

Aplicación web para la gestión de contactos desarrollada para la materia de Diseño y Programación de Software Multiplataforma.

##  Funcionalidades
* **Visualización:** Carga inicial de contactos desde archivo JSON.
* **Gestión:** Permite agregar nuevos contactos y eliminarlos.
* **Favoritos:** Permite marcar contactos como favoritos, los cuales se ordenan automáticamente al inicio de la lista y se resaltan visualmente (azul).


##  Tecnologías
* React + Vite
* CSS3 (Grid y Flexbox)
* Git & GitHub

##  Proceso de instalacion Instalación
1.  Clonar el repositorio " git remote add origin https://github.com/Chris103105/Desafio-practico--1.git "
2.  Ejecutar `npm install`.
